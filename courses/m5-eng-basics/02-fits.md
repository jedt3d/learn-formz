# 2. เผื่อเท่าไรถึงสวมพอดี: Tolerance & Fit
{% include meta.html %}

## 🎯 จบบทนี้แล้วเราจะ...
- รู้จัก **tolerance** (ขนาดเพี้ยนได้เท่าไร) และ **fit** (คับ / พอดี / หลวม)
- เลือก **clearance** ของฝาสวมตามวิธีผลิต

## 💡 ไอเดียสั้น ๆ

| fit | ความรู้สึก | ระยะเผื่อต่อข้าง 3D print FDM 🔍 | ตัวอย่างในบ้าน |
|---|---|---|---|
| **Press fit** (แน่น) | ต้องกดถึงเข้า ไม่หลุดเอง | 0.0–0.1 | จุกปากกา |
| **Snug fit** (พอดี) | สวมด้วยมือ มีแรงฝืด | 0.15–0.25 | ฝากล่องดินสอ ✅ |
| **Clearance fit** (ลื่น) | หมุนหรือเลื่อนได้ | 0.3–0.5 | ฝาเกลียว (C8 ใช้ 0.4) |

ตัวเลขเป็นจุดเริ่มต้นสำหรับเครื่องพิมพ์ทั่วไป ขึ้นกับเครื่องและวัสดุ ควรพิมพ์ **ชิ้นทดสอบ** ก่อนเสมอ

## 👣 ลงมือทำ (2 นาที)
1. ช่องในกล่อง (จากบท 1) เช่น 52.0 × 20.0
2. ฝาด้านใน = ช่อง **+ 0.2 ต่อข้าง** → 52.4 × 20.4
3. เขียนค่าที่ใช้ลงในชื่อ object เช่น `lid_fit+0.2` (Objects palette)
4. พิมพ์ชิ้นทดสอบวงแหวนสั้น 5 mm ที่ 0.1 / 0.2 / 0.3 แล้วเลือกค่าที่ชอบ
