## 🗺️ ภาพรวม: ทั้งแคตตาล็อกในงานเดียว
```
Brief → วัด/ถ่ายรูป (Underlay)            ← C2
  → เลือกเทคนิค (Solid / NURBS / SubD)    ← C1–C3
  → Split + รายละเอียด                    ← C2, C8
  → ตรวจ (Zebra · Doctor · Print Prep)    ← C3, C7, C8
  → CMF + Render                          ← C4
  → (Animation turntable)                 ← C5
  → บอร์ด + แบบ                           ← C6, C7
  → STEP / STL                            ← C8
```

## 🤔 ทำไมต้องมี capstone?
แต่ละ course สอนเครื่องมือทีละกลุ่ม ส่วน capstone ฝึก **การตัดสินใจ** ว่าใช้อะไร เมื่อไร และทำไม ซึ่งเป็นสิ่งที่ product designer ใช้ทุกวัน งานนี้เป็น **portfolio ชิ้นแรก** ที่ใช้ยื่นเข้ามหาวิทยาลัยหรือฝึกงานได้

## ✅ ตอนนี้เราทำได้แล้ว
- [x] เขียน brief และหาจุดที่ปรับปรุงได้จากของจริง
- [x] เลือกเทคนิคโมเดลให้เหมาะกับรูปทรง
- [x] ปั้นฟอร์มอิสระด้วย Subdivision + Symmetry
- [x] แยกชิ้นพร้อม parting line
- [x] ตรวจงานด้วย check-list 6 ข้อ
- [x] ทำ hero render, บอร์ด, แบบ และไฟล์ผลิตครบชุด

## 🏆 ภารกิจโบนัส
1. **Turntable 10 วินาที** ของเมาส์ (C5) ใส่ลิงก์ในบอร์ด
2. **Capstone #2:** เลือกของอื่นที่ใช้เทคนิคต่างกัน (เช่น ไฟฉาย Revolve + Helix)
3. **Critique:** ให้เพื่อนหรือครูดูบอร์ด แล้วจด feedback 3 ข้อ และแก้ 1 ข้อ

{: .power }
**จาก "formZ คืออะไร?" สู่ portfolio ภายใน ~13 ชั่วโมง** ซึ่งทุกขั้นทำในโปรแกรมเดียว ทั้ง solid, NURBS, SubD, เรนเดอร์, animation, layout, แบบ และไฟล์ผลิต
