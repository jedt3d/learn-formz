# C9 · Capstone: ของจากบ้านตั้งแต่ต้นจนจบ
{: .no_toc }

<span class="tag tag-designer">Designer</span><span class="tag tag-eng">Engineering</span><span class="tag tag-ready">พร้อมเรียน</span> ⏱ รวมประมาณ **90 นาที** (อ่าน ~40 + ลงมือ ~50) · 11 บท

**จบ course นี้แล้วเราจะได้:** **portfolio project ชิ้นแรก** เป็นของที่เราเลือกเองจากบ้าน ทำครบตั้งแต่ brief → วัด → โมเดล → ตรวจ → เรนเดอร์ → บอร์ด → ไฟล์ผลิต

ตัวอย่างหลักในบทเรียนคือ **เมาส์คอมพิวเตอร์** (ฟอร์มอิสระด้วย Subdivision) แต่ทุกบทมีกล่อง 🔀 **"ถ้าเลือกของอื่น"** เช่น แปรงสีฟัน, ที่ตัดเทป, ไฟฉาย, กระปุกออมสิน
