## 🧭 ทำไมต้องเรียนสิ่งนี้
งานที่ดีแต่ **เล่าเรื่องไม่เป็น** มักไม่ผ่าน board คือ **ภาษาของนักออกแบบ** ใช้ทั้งในการประกวด สมัครเรียนต่อ และนำเสนอลูกค้า

| ทักษะ | เครื่องมือ |
|---|---|
| ภาษาออกแบบ / family | Revolve, Pipe, CMF ชุดเดียว |
| จัดหน้า | grid + hierarchy + thumbnail |
| กระดาษ | **New Layout Project**, Sheets palette |
| ภาพ | **Place Image / Place Image Fit** (ลิงก์ไฟล์) |
| มุมมองจริง | **Place Frame / Place Multi-Frame** (ลิงก์โมเดล) |
| แบรนด์ | Place Text, โลโก้, swatches |
| ส่งงาน | Print → PDF |

## ✅ ตอนนี้เราทำได้แล้ว
- [ ] ออกแบบสินค้าเป็น **ชุด** ที่ดูเป็นครอบครัวเดียวกัน
- [ ] จัด board A3 แบบมีลำดับความสำคัญ
- [ ] วาง views ที่ลิงก์กับโมเดลและอัปเดตได้
- [ ] ส่งออก PDF ที่พร้อมพิมพ์

{: .power }
โมเดล ภาพเรนเดอร์ animation และ board ทั้งหมดอยู่ใน **โปรแกรมเดียว** และแก้โมเดลแล้ว board ตามได้

## 🎁 โจทย์เสริม
- ทำ board ที่ 3 เป็น **"story board"** แสดงการใช้งาน 3 ขั้น (เติมน้ำ → ต้ม → ริน) ด้วยภาพเรนเดอร์ 3 ภาพ
- เพิ่ม **ภาพนิ่งจากวิดีโอ C5** ลงใน board ของแม็กเย็บ
