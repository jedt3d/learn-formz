# 7. ตัวหนังสือ โลโก้ สี
{% include meta.html %}

## 🎯 จบบทนี้แล้วเราจะ...
- ใส่ชื่อสินค้าและคำโปรยด้วย **Place Text** (เลือกฟอนต์และขนาดใน Text Editor)
- วางโลโก้แบรนด์ (PNG จาก C4) ด้วย **Place Image**
- ทำ **color swatches** จากสี CMF

## 💡 ไอเดียสั้น ๆ
ตัวหนังสือบน board ควร **น้อยแต่ชัด** ใช้ 3 ขนาด: ชื่อสินค้า (ใหญ่) · คำโปรย (กลาง) · ข้อมูล (เล็ก)

| ข้อความ | ขนาดบน A3 (ประมาณ) |
|---|---|
| ชื่อสินค้า เช่น "MORNING Kettle & Mug" | 18–24 mm |
| คำโปรย 1 ประโยค | 6–8 mm |
| ข้อมูล: วัสดุ ความจุ ขนาด | 3.5–4 mm |

## 👣 ลงมือทำ (5 นาที)
1. **Place Text** คลิกที่ตำแหน่งชื่อ → พิมพ์ชื่อสินค้าใน Text Editor แล้วเลือกฟอนต์และขนาด
2. ทำซ้ำกับคำโปรยและข้อมูล (ฟอนต์ไม่เกิน 2 แบบ)
3. **Place Image** โลโก้ (PNG พื้นโปร่งใส) วางมุมบน
4. **Swatches:** วาด **Rectangle** 20 × 20 mm 3 อัน แล้วใส่สีแบบเดียวกับ CMF (สแตนเลส / ดำ / ขาว) พร้อมพิมพ์ชื่อวัสดุใต้แต่ละอัน
5. ใส่ชื่อเรา + วันที่ที่มุมล่างขวา แล้วบันทึก

- ตัวหนังสือภาษาไทยใน Place Text ของ formZ 10: ให้ทดสอบว่าฟอนต์ไทย (เช่น IBM Plex Sans Thai, Sarabun) แสดงสระและวรรณยุกต์ถูกต้องหรือไม่ ถ้าไม่ถูก ให้ทำข้อความไทยเป็นภาพ PNG แล้วใช้ Place Image แทน
- การเติมสีให้ Rectangle บน layout (fill / hatch / material) ต้องยืนยันวิธีใน v10

{: .warning }
ห้ามใส่ข้อมูลส่วนตัว (ที่อยู่ เบอร์โทร รูปหน้า) บน board ที่จะเผยแพร่ ใช้แค่ชื่อเล่นหรือชื่อแบรนด์สมมติ

## ✅ เช็คตัวเอง
