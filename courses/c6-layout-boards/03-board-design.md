# 3. บอร์ดดีมี 3 ระดับ: hierarchy · grid · ช่องว่าง
{% include meta.html %}

## 🎯 จบบทนี้แล้วเราจะ...
- รู้จักองค์ประกอบของ **presentation board** สินค้า
- ใช้ **grid** และ **ลำดับความสำคัญ (hierarchy)** วางของบนหน้า
- ร่าง **thumbnail** 3 แบบบนกระดาษก่อนลงมือในโปรแกรม

## 💡 ไอเดียสั้น ๆ
คนดู board ใช้เวลาแค่ **3 วินาทีแรก** ตัดสินว่าน่าสนใจไหม จึงต้องมี **จุดเด่นจุดเดียว** (hero) ชัด ๆ

| ลำดับ | อะไร | สัดส่วนพื้นที่ (ประมาณ) |
|---|---|---|
| ① | **ภาพ Hero** | 50–60% |
| ② | ชื่อแบรนด์/สินค้า + คำโปรย 1 ประโยค | 10% |
| ③ | ภาพรอง (detail, การใช้งาน) | 20% |
| ④ | สี (swatches), วัสดุ, ขนาดหลัก | 10% |
| ⑤ | ชื่อเรา / วันที่ / รุ่นงาน | มุมล่าง เล็ก ๆ |

**กฎ 3 ข้อ:** เว้นที่ว่าง (white space) อย่างน้อย 20% · ใช้ฟอนต์ไม่เกิน 2 แบบ · ใช้สีที่มาจาก CMF ของสินค้าเท่านั้น

## 👣 ลงมือทำ (3 นาที)
1. วาดสี่เหลี่ยมสัดส่วน A3 แนวนอน 3 อัน บนกระดาษ
2. ร่าง layout 3 แบบ: ภาพใหญ่ซ้าย / ภาพใหญ่เต็มหน้า + แถบข้อความ / ภาพใหญ่ตรงกลาง
3. เลือก 1 แบบ แล้วถ่ายรูปเก็บไว้ (ใช้ประกอบการบ้าน)
