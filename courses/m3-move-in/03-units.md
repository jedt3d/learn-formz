# 3. ขั้น 3 · ตรวจหน่วยและขนาดให้ถูก
{% include meta.html %}

## 🎯 จบบทนี้แล้วเราจะ...
- ตั้ง **Project Settings** เป็น **mm**
- วัดด้วย **Measure Distance** แล้วแก้ด้วย **Scale** ถ้าขนาดผิด

## 💡 ไอเดียสั้น ๆ
ถ้าวัดได้ 10× / 25.4× ของที่ควรเป็น แปลว่าหน่วยของไฟล์ต้นทางต่าง (cm หรือ inch) แค่ Scale ด้วยตัวเลขนั้นก็กลับมาเหมือนเดิม

## 👣 ลงมือทำ (3 นาที)
1. ตรวจ **Project Settings** › Units = **Millimeters**
2. **Measure Distance** วัดความยาวที่รู้ค่าจริง (เช่นปากกา 140)
3. ถ้าได้ 14 → **Scale** ×10 / ถ้าได้ 5.51 → **Scale** ×25.4
4. วัดซ้ำ
