## 🧭 เราเพิ่งทำอะไรไป
ใน ~90 นาที เราทำ **workflow ของนักออกแบบผลิตภัณฑ์ครบรอบ** แบบย่อ

| ขั้น | ใน C1 เราใช้ | ในงานจริงคือ |
|---|---|---|
| ① สังเกตและวัด | ไม้บรรทัด + ภาพถ่าย | ศึกษาผลิตภัณฑ์ที่มีอยู่ (benchmark) |
| ② ตั้งค่าเครื่องมือ | Template mm + Snap | มาตรฐานของทีม/บริษัท |
| ③ ขึ้นรูป | Cylinder, Cone, Controlled Round, Union, Difference | 3D CAD modeling |
| ④ ใส่ผิว | Materials + Catcher | CMF (Color, Material, Finish) |
| ⑤ นำเสนอ | RenderZone + มุมกล้อง Hero | ภาพนำเสนอลูกค้าหรือ portfolio |

## ✅ ตอนนี้เราทำได้แล้ว
- [ ] หาเครื่องมือใดก็ได้ด้วย **Assistant**
- [ ] เปิดไฟล์ใหม่ที่เป็น **mm** พร้อมใช้ทันทีจาก **template**
- [ ] สร้าง primitive ที่ **ขนาดตรงเป๊ะ** และแก้ทีหลังได้
- [ ] ลบมุมแบบแก้ได้ (Controlled Round) และใช้ **Boolean** ได้ 2 แบบ
- [ ] ใส่ **material** วางของบน **พื้นสตูดิโอ** และ **เรนเดอร์** ภาพได้เอง

{: .easy }
ลองนับดู: เราใช้เครื่องมือแค่ประมาณ **12 ตัว** และตั้งค่า RenderZone แค่ **4 ค่า** ก็ได้ภาพระดับ portfolio แล้ว formZ ที่ตั้งค่าถูกตั้งแต่แรกไม่ได้ยากกว่า SketchUp เลย

{: .power }
สิ่งที่เราทำใน C1 แต่ SketchUp ทำเองในตัวไม่ได้: **solid ที่ปิดสนิทจริง**, **ลบมุมแบบแก้ได้**, **กรวยปลายตัดที่ใส่ % ได้** และ **เรนเดอร์ภาพเสมือนจริงในตัว**

## 🎁 โจทย์เสริม (ไม่บังคับ)
- **เปลี่ยนสี 3 แบบ:** ทำซ้ำ `MK_Cap_Color` เป็น 3 สี แล้วเรนเดอร์เทียบกัน แบบนี้เรียกว่า *colorway* ซึ่งนักออกแบบทำกันจริง
- **[Pebble Speaker]({{ '/courses/c1-quick-win/bonus-speaker/' | relative_url }})**: ลำโพงจิ๋วทรงกระบอก ฝึกเทคนิคชุดเดียวกันกับชิ้นที่ใหญ่ขึ้น
