# 2. Render สวยครั้งแรกใน 3 ขั้น: วัสดุ → แสง → ถ่าย
{% include meta.html %}

## 🎯 จบบทนี้แล้วเราจะ...
- จำ **สูตร 3 ขั้น** ที่ใช้ได้กับทุกงาน: **วัสดุ → แสง → ถ่าย**
- เห็นภาพก่อน/หลังว่าแต่ละขั้นเปลี่ยนภาพอย่างไร

## 💡 สูตร 3 ขั้น
| ขั้น | ทำอะไร (เวลา) | ทำไม |
|---|---|---|
| ① **วัสดุ** | ให้ทุกชิ้นมี **reflection** เล็กน้อย (พลาสติกเงา) และอย่าใช้สีเทา default (2 นาที) | ของจริงสะท้อนแสงเสมอ |
| ② **แสง** | ไฟใหญ่ 1 ดวงเฉียงจากซ้ายบน + **Environment** สว่างอ่อน ๆ (2 นาที) | ไฟใหญ่ = เงานุ่ม ดูแพง |
| ③ **ถ่าย** | กล้องมุม 3/4 ต่ำลงนิดหนึ่ง ให้ชิ้นงานเต็ม ~60% ของภาพ (2 นาที) | มุมต่ำทำให้ชิ้นงานดูใหญ่และน่าสนใจ |

## 👣 ลงมือทำ (6 นาที)
1. ใช้ปากกาจากบทที่แล้ว render ภาพ **ก่อน** ไว้ 1 ภาพ (`before.png`)
2. **วัสดุ:** เปิด material ของปลอกแล้วเพิ่ม Reflection เล็กน้อย (ดูชั้น Reflection ใน C4 บท 3)
3. **แสง:** ย้ายไฟหลักไปซ้ายบน 45° และขยายขนาดแผ่นไฟ (Area light) ให้ใหญ่ขึ้น
4. **ถ่าย:** หมุนกล้องเป็นมุม 3/4 แล้วลดความสูงกล้องลง บันทึกเป็น view `Hero2`
5. render ภาพ **หลัง** (`after.png`) แล้ววางคู่กัน
