# 5. palette 12 เครื่องมือของเราเอง
{% include meta.html %}

## 🎯 ทริกนี้
รวมเครื่องมือที่ใช้บ่อยใน product design ไว้ใน **palette เดียว** ไม่ต้องคลิกหาเครื่องมือในเมนูย่อย

## 💡 อยู่ตรงไหน (R1: Tool Manager and Favorites)
**Workspaces › Tool Manager** (คำสั่งล่างสุดของเมนู)
- **Categories / Tools**: เลือกหมวดแล้ว **ลากไอคอน** ไปวางบน palette
- **New Tool Palette...**: ตั้ง **Tool Palette Name**, **Tool Icon Size** และ **Show Tool Names**
- คลิกขวาบน palette → **Settings...** / **Restore Defaults**

**ชุดแนะนำ "PD Favorites" (12 ตัว):**
Pick · Cube · Cylinder · Vector Line · Spline · 3D Extrusion · Revolve · Union · Difference · Controlled Round · Thicken · Subdivision / Create

## 👣 ลองเลย (4 นาที)
1. **Workspaces › Tool Manager › New Tool Palette...** ชื่อ `PD Favorites`, เปิด Show Tool Names
2. ลากเครื่องมือ 12 ตัวเข้า palette (ลากเป็นแถวยาว = palette แนวนอน)
3. วาง palette ไว้ด้านซ้ายของจอ
4. บันทึก workspace (เมนู **Workspaces**) เพื่อให้ palette อยู่ทุกครั้งที่เปิดโปรแกรม
