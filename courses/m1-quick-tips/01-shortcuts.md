# 1. ปุ่มลัดแบบ SketchUp ในคลิกเดียว
{% include meta.html %}

## 🎯 ทริกนี้
ใครเคยใช้ SketchUp หรือ Rhino มาก่อน formZ **โหลดชุดปุ่มลัดของโปรแกรมนั้นมาให้ได้เลย**

## 💡 อยู่ตรงไหน
**Edit › Key Shortcuts...** → เปิด **Key Shortcuts Manager**
- **Category / Entry**: หมวดและคำสั่ง
- **Add... / Edit... / Delete**: เพิ่ม แก้ หรือลบปุ่มลัด
- **Save... / Load...**: บันทึกชุดปุ่มลัดเป็นไฟล์ (เอาไปใช้เครื่องอื่นได้)
- **Load Defaults...** → **Default** (formZ) · **Preset 1** (แบบ Rhino) · **Preset 2** (แบบ SketchUp)

เมื่อเลือก preset แล้ว เมนู **Orbit/Spin** และ **Pan** จะเปลี่ยนตามไปด้วย (R1: Key Shortcuts)

## 👣 ลองเลย (3 นาที)
1. **Edit › Key Shortcuts... › Load Defaults... › Preset 2**
2. ลองหมุนและเลื่อนมุมมองด้วยเมาส์แบบที่คุ้นมือ
3. **Save...** เป็น `my_keys` ไว้ใน Google Drive หรือ USB
4. ถ้าไม่ชอบ กลับไปที่ **Load Defaults › Default**
