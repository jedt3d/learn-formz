# 7. สรุป M1: 8 ทริกของเรา
{% include meta.html %}

## 🗺️ ภาพรวม
| ทริก | ใช้เมื่อ | ประหยัดเวลา |
|---|---|---|
| **Key Shortcuts Preset 2** | ย้ายมาจาก SketchUp | ไม่ต้องจำปุ่มใหม่ |
| **Nudge 0.5 mm** | จัดตำแหน่งละเอียด | ไม่ต้องพิมพ์ค่า |
| **Taps** | สลับโหมดระหว่างลาก | ไม่ต้องละมือ |
| **Shift+Space Guides** | วาดให้ตรงแนว | ไม่ต้องคำนวณ |
| **PD Favorites** | ทุกวัน | ไม่ต้องหาเครื่องมือ |
| **Place On** | ของซ้ำบนผิว | คลิกเดียวแทน 36 คลิก |

## 🤔 ทำไมต้องรู้?
"ใช้ยาก" มักแปลว่า **ยังตั้งค่าไม่เข้ามือ** ทริกพวกนี้ทำให้ formZ เร็วพอ ๆ กับ SketchUp แต่ยังมีพลังของ solid, NURBS และ SubD ครบ

## ✅ ตอนนี้เราทำได้แล้ว
- [x] โหลดและบันทึกชุดปุ่มลัด
- [x] ใช้ nudge, taps และ guides แทนการพิมพ์ค่า
- [x] มี tool palette ของตัวเอง
- [x] วางของซ้ำด้วย Place On

## 🏆 ภารกิจโบนัส
