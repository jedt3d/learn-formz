# 3. Taps: แตะปุ่มเดียวเปลี่ยนโหมด
{% include meta.html %}

## 🎯 ทริกนี้
ระหว่างที่ใช้เครื่องมืออยู่ **แตะ** (กดแล้วปล่อยเร็ว ๆ) ปุ่ม Shift / Ctrl(Cmd) / Alt(Option) เพื่อ **สลับโหมด** ได้ทันทีโดยไม่ต้องไปกด palette

## 💡 ตัวที่ใช้บ่อย (R1: Taps)

| ขณะใช้ | แตะ | ผล |
|---|---|---|
| **Pick** (ลากชิ้นงาน) | Ctrl/Cmd | สลับเลื่อน **ตั้งฉาก** กับ **ขนาน** reference plane |
| **Pick** (ลาก) | Shift | สลับให้ snap กับตำแหน่งเดิมได้หรือไม่ได้ |
| **Pick** (ลากเพื่อ transform) | Alt/Option | สลับระหว่าง **copy** กับย้ายตัวเอง |
| **Area Pick** | Ctrl/Cmd | สลับเลือกกับยกเลิกเลือก |
| **Rectangle / Circle / Ellipse** | Shift | เปิด/ปิด **Insert** |
| **Vector Line / Spline** | Ctrl/Cmd | สลับวาด **ตั้งฉาก/ขนาน** กับ reference plane |

taps เป็นค่าที่ระบบตั้งไว้ **ตั้งเองไม่ได้**

## 👣 ลองเลย (3 นาที)
1. **Pick** ลากปากกาบนพื้น แล้วแตะ **Ctrl/Cmd** ปากกาจะเลื่อนขึ้นลงแนวตั้งได้
2. ลากอีกครั้ง แตะ **Alt/Option** แล้วปล่อย จะได้สำเนา
3. **Vector Line** วาดเส้นบนพื้น แตะ **Ctrl/Cmd** แล้วลากเส้นขึ้นไปในแนวตั้ง

{: .shot }
[SCREENSHOT: ลากปากกาขึ้นแนวตั้งด้วย tap Ctrl/Cmd]

{: .power }
SketchUp ใช้ปุ่มลูกศรล็อกแกน ส่วน formZ มี taps ที่ทำงานต่างกันตามเครื่องมือ จึงทำงานได้โดยไม่ต้องละมือจากเมาส์
