# 4. ฝาที่ขันได้: clearance 0.4 mm
{% include meta.html %}

## 🎯 จบบทนี้แล้วเราจะ...
- ทำฝาที่มี **เกลียวใน** ซึ่งเป็นภาพกลับด้านของเกลียวนอก
- คำนวณ **clearance 0.4 mm** ในแนวรัศมี
- ใส่ร่องกันลื่นรอบฝาด้วย Insert หรือ Difference แบบกระจายรอบวง

## 💡 ไอเดียสั้น ๆ

| ส่วน | รัศมี (mm) |
|---|---|
| ผิวคอขวด | 11.0 |
| ยอดเกลียวนอก | 12.2 |
| **รูในฝา** (ยอดเกลียวนอก + 0.4) | **12.6** |
| ยอดเกลียวใน (ยื่นเข้ามา 1.2) | 11.4 (ห่างจากผิวคอ 0.4 ✅) |
| ผิวนอกฝา | 14.0 (ผนัง 1.4 + เนื้อเกลียว) |

## 👣 ลงมือทำ (5 นาที)
1. **Cylinder** R **14** H **14** วางแยกไว้ข้างขวด (เช่น x = 50) ตั้งชื่อ `Cap`
2. **Difference** ด้วย Cylinder R **12.6** H **12.4** จากด้านล่าง (เหลือหลังคาฝาหนา 1.6)
3. ระนาบ ZX ที่ศูนย์กลางฝา วาดสามเหลี่ยมชี้เข้าด้านใน: (12.6, 2) → (11.4, 3.2) → (12.6, 4.4) แล้ว **Helix** ใช้ค่าเดิม (3 รอบ, pitch 3, ทิศเดียวกัน, Caps)
4. **Union** เกลียวในเข้ากับผนังฝา (ให้ฐานจมในผนัง 0.1)
5. **ร่องกันลื่น:** ทำกล่องเล็ก 1 × 1.2 × 12 ที่ผิวนอกฝา แล้วใช้ **Rotate** + copy ทำซ้ำรอบวง 24 อัน (ทุก 15°) จากนั้น **Difference** ทั้งชุดออกจากฝา
