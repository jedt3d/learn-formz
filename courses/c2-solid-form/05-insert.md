# 5. Insert: ร่องรองลวด
{% include meta.html %}

## 🎯 จบบทนี้แล้วเราจะ...
- ใช้ตัวเลือก **Insert** วาดลงบนหน้าของ solid แล้ว "ขุด" หรือ "เติม" เนื้อวัสดุได้ทันที
- รู้จักโหมด **Cut and Fill / Cut / Fill**
- ทำร่อง (anvil) ที่ลวดเย็บพับบนฐาน

## 💡 ไอเดียสั้น ๆ
ถ้าเปิด **Insert** แล้ววาดลงบนหน้าของวัตถุ สิ่งที่วาดจะ **รวมเข้าไปในวัตถุเดิม** ไม่ได้เป็นชิ้นใหม่ เมื่อใช้คู่กับ 3D Extrusion:

| โหมด (Insert menu) | ผล |
|---|---|
| **Cut and Fill** | ดึงขึ้น = เติม · ดึงลง = ขุด |
| **Cut** | ขุดเสมอ |
| **Fill** | เติมเสมอ |

เคอร์เซอร์จะมีเครื่องหมาย **+** เมื่อวางบนหน้าที่ insert ได้ (R1: Drawing Objects)

## 👣 ลงมือทำ (3 นาที)
1. เลือก **Rectangle**, object type **3D Extrusion**, เปิด **Insert** และเลือก **Cut**
2. เลื่อนเมาส์ไปบน **หน้าบน** ของฐาน (ดูว่ามี +) แล้ววาดสี่เหลี่ยม **14 × 4 mm** ห่างจากปลายด้านหน้า (ฝั่ง x = 130 ซึ่งเป็นฝั่งที่ใช้เย็บ) ประมาณ 10 mm และอยู่กึ่งกลางความกว้าง (ใช้ **Plane Delta** ช่วยวัดระยะ)
3. ใส่ Height **1** แล้วกด Enter จะได้ร่องลึก 1 mm บนฐาน
4. หมุนดูใกล้ ๆ แล้วบันทึกไฟล์

{: .shot }
[SCREENSHOT: เคอร์เซอร์ + บนหน้าบนของฐาน และร่อง 14 × 4 × 1 mm]

{: .easy }
นี่คือ **Push/Pull ลงไปในหน้า** แบบ SketchUp ซึ่งคนชอบที่สุด formZ ก็ทำได้ แถมเลือกได้ว่าจะขุดหรือเติมแน่ ๆ

{: .power }
ผลลัพธ์ยังเป็น **solid ชิ้นเดียวที่ปิดสนิท** ไม่มีผิวซ้อนหรือรูรั่วแบบที่ SketchUp มักเกิดเมื่อดันหน้าทะลุ

{: .shapr }
Shapr3D: วาดบนหน้าแล้ว push ลง = ตัด · formZ: **Insert + Cut**

## ✅ เช็คตัวเอง
<details><summary>1. ถ้าลืมเปิด Insert จะเกิดอะไรขึ้น?</summary>จะได้กล่องชิ้นใหม่วางทับหน้า ไม่ได้ขุดลงไปในฐาน</details>
<details><summary>2. โหมดไหนที่ดึงขึ้นแล้วเติมเนื้อ?</summary>Cut and Fill (ดึงขึ้น) หรือ Fill</details>
<details><summary>3. Keep Edges ทำอะไร?</summary>เก็บเส้นขอบของหน้าที่อยู่ระนาบเดียวกับชิ้นที่ insert ไว้ (ปกติจะลบ)</details>
