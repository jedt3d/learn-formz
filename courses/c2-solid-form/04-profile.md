# 4. โปรไฟล์โค้ง: Vector Line + Arc
{% include meta.html %}

## 🎯 จบบทนี้แล้วเราจะ...
- วาดรูปปิดที่มี **เส้นตรงผสมเส้นโค้ง** ในรูปเดียว (composite shape)
- ปิดรูปด้วยปุ่ม **c** และได้ solid ด้วย **3D Extrusion**
- ได้ "ตัวบน" ของแม็กเย็บจากโปรไฟล์ด้านข้าง

## 💡 ไอเดียสั้น ๆ
เครื่องมือวาดรูปเปิด เช่น **Vector Line**, **Arc** และ Spline **สลับกันได้ระหว่างวาด** เช่น ลากเส้นตรง 3 เส้น แล้วเปลี่ยนเป็น Arc เพื่อทำหลังโค้ง แล้วปิดรูป (R1: Drawing Objects)

| ปุ่ม / ท่า | ผล |
|---|---|
| คลิกกลับที่จุดแรก หรือกด **c** หรือ triple-click | ปิดรูป |
| กด **e** หรือ double-click | จบเป็นรูปเปิด |

**โปรไฟล์ตัวบน** (วาดบนระนาบ **ZX** ค่าเป็น x, z หน่วย mm)

| จุด | (x, z) |
|---|---|
| A | (12, 14) |
| B | (130, 14) |
| C | (130, 34) |
| Arc ผ่าน | (70, 46) |
| D | (12, 34) แล้วปิดกลับ A |

## 👣 ลงมือทำ (5 นาที)
1. สลับ reference plane เป็น **ZX** (ภาพ Underlay จาก บทที่ 1 จะโผล่ขึ้นมา)
2. เลือก **Vector Line** แล้วเลือก object type **3D Extrusion**
3. คลิก A → B → C (พิมพ์พิกัดใน Input palette หรือ snap ตามกริด)
4. สลับไปเครื่องมือ **Arc** ระหว่างวาด แล้ววาดโค้งผ่านจุด (70, 46) ไปจบที่ D
5. กด **c** เพื่อปิดรูปกลับไปที่ A
6. ใส่ **Height = 28** แล้วกด Enter จะได้ solid หนา 28 mm ตามแนวแกน Y
7. เทียบกับ Underlay: ถ้าโค้งไม่ตรงกับแม็กของเรา ให้ Undo แล้วปรับจุดใหม่ จากนั้นตั้งชื่อ `Upper` และบันทึกไฟล์

{: .verify }
- ชื่อเครื่องมือ **Arc** มีหลายวิธีวาด (เช่น 3 จุด หรือจุดศูนย์กลาง) ให้ยืนยันว่าวิธีไหนวาด "ผ่านจุด" ได้ตรงที่สุดใน v10
- ทิศของ Height บนระนาบ ZX (+Y หรือ −Y) ต้องยืนยันกับหน้าจอจริง ถ้าออกไปฝั่ง −Y ไม่เป็นไร เพราะบทที่ 6 จะจัดให้ตรงกลางฐาน

{: .easy }
เหมือนการวาดด้วย Line + Arc แล้ว Push/Pull ใน SketchUp แต่ formZ ได้ solid ทันที และกด **c** เพื่อปิดรูปได้เลย

{: .shapr }
นี่คือ **sketch → extrude** แบบ Shapr3D เป๊ะ ๆ ต่างกันแค่ใน formZ เราเลือก object type ไว้ล่วงหน้า

## ✅ เช็คตัวเอง
