# 8. ขอบมน 4 ชุดในครั้งเดียว + Round to Holdline
{% include meta.html %}

## 🎯 จบบทนี้แล้วเราจะ...
- ใช้ **Controlled Round** แบบ **หลาย set** (ขอบละรัศมีไม่เท่ากัน) ในชิ้นเดียว
- เลือกเส้นต่อเนื่องที่สัมผัสกันได้ในคลิกเดียว (command-click)
- รู้ว่า **Round to Holdline** ใช้ทำขอบมนที่ **รัศมีเปลี่ยนไปตามเส้น**

## 💡 ไอเดียสั้น ๆ
ขอบใหญ่ = ดูนุ่ม เป็นมิตร · ขอบเล็ก = ดูแม่นยำ แข็งแรง แม็กเย็บที่ดูดีมักใช้ **2–3 ขนาด** ในชิ้นเดียว

| ชิ้น | ขอบ | รัศมี |
|---|---|---|
| Base | มุมแนวตั้งด้านหน้า 2 มุม | R15 |
| Base | ขอบบนรอบชิ้น | R2 |
| Cover | ขอบโค้งด้านบนทั้งสองข้าง | R4 |
| Cover | ขอบด้านหน้า | R2 |

ใน Controlled Round แต่ละ **set** มีค่าของตัวเอง กด **+** เพื่อเพิ่ม set และ **command-click** เพื่อเลือกเส้นที่ต่อกันแบบสัมผัส (tangent) ทั้งแนวในคลิกเดียว (R1: Controlled Round)

## 👣 ลงมือทำ (5 นาที)
1. **Controlled Round** คลิก `Base` · set 1: คลิกมุมแนวตั้งด้านหน้า 2 มุม แล้วตั้ง **R15**
2. กด **+** · set 2: command-click ขอบบนรอบชิ้น แล้วตั้ง **R2**
3. ทำแบบเดียวกันกับ `Cover`: set 1 เป็น R4 (ขอบโค้งบนทั้งสองข้าง) และ set 2 เป็น R2 (ขอบหน้า)
4. `Magazine` ลบมุมหน้าเล็ก ๆ **R1** ก็พอ
5. หมุนดูใน **Shaded Full** ขอบมนจะรับแสงเป็นเส้นไฮไลต์สวย ๆ แล้วบันทึกไฟล์

### ลองเสริม: Round to Holdline (2 นาที)
**Round to Holdline** สร้างขอบมนระหว่างหน้าโดยใช้ **holdline** คือเส้นโค้งที่อยู่บนหน้าข้าง ๆ ขอบ ซึ่งกำหนดว่ารอยมนจะกว้างไปถึงไหน ดังนั้นรัศมีจะเปลี่ยนไปตามเส้น เหมาะกับขอบแบบ "เรียวลง" ที่เห็นบนเมาส์หรือรถยนต์ (R1: Round to Holdline)
- วาด Spline บน **หน้าข้าง** ของ Magazine ให้ยาวตลอดขอบ แล้วใช้ Round to Holdline คลิกขอบแล้วคลิกเส้น

{: .verify }
ลำดับการคลิกของ Round to Holdline ใน v10 ยังไม่ได้ยืนยัน ให้ดูจาก Action palette ตอนใช้งานจริง

{: .warning }
ลบมุม **ก่อน** Thicken (บทถัดไป) เพราะถ้าทำ Thicken ก่อนแล้วค่อยลบมุม ขอบด้านในจะลบมุมยากกว่ามาก

{: .power }
SketchUp ทำขอบที่ **รัศมีเปลี่ยนไปตามเส้น** ไม่ได้ ต้องใช้โปรแกรม NURBS หรือ CAD ระดับสูง แต่ใน formZ มีเครื่องมือนี้ในตัว

{: .shapr }
Shapr3D: เลือกหลายขอบแล้วกด Fillet ค่าเดียว · formZ: **Controlled Round แบบหลาย set** (แต่ละ set แก้ทีหลังได้)

## ✅ เช็คตัวเอง
<details><summary>1. ทำไมต้องแยก set?</summary>เพื่อให้แต่ละกลุ่มขอบมีรัศมีของตัวเอง และแก้แยกกันได้</details>
<details><summary>2. Command-click ตอนเลือกขอบทำอะไร?</summary>เลือกเส้นที่ต่อกันแบบสัมผัส (tangent) ทั้งแนว</details>
<details><summary>3. Holdline คืออะไร?</summary>เส้นบนหน้าข้างขอบที่กำหนดว่ารอยมนกว้างไปถึงไหน</details>
