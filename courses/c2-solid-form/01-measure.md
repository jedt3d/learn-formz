# 1. วัด 5 ค่า + วางรูปเป็นแบบ (Underlay)
{% include meta.html %}

## 🎯 จบบทนี้แล้วเราจะ...
- วัดแม็กเย็บของจริง แล้วสรุปเป็น **ขนาดหลัก 6 ค่า**
- เอาภาพถ่ายด้านข้างไปวางบน reference plane เป็น **Underlay**
- ปรับขนาดภาพให้ตรงกับไม้บรรทัดในภาพ

## 💡 ไอเดียสั้น ๆ
แม็กเย็บดูซับซ้อน แต่ถ้ามองจาก **ด้านข้าง** จะเห็นว่าเป็นแค่ **3 แผ่นโปรไฟล์** วางซ้อนกัน คือ ฐาน, รางลวด และฝาบน ซึ่งเป็นวิธีคิดเดียวกับ Shapr3D คือ **วาดโปรไฟล์ 2D แล้วดึงเป็น 3D**

**ขนาดตัวอย่าง** (แม็กเย็บตั้งโต๊ะขนาดกลาง ถ้าของเราขนาดต่างไป ให้ใช้ของเรา)

| ค่า | ตัวอย่าง |
|---|---|
| ความยาวฐาน | 130 mm |
| ความกว้างฐาน | 35 mm |
| ความหนาฐาน | 10 mm |
| ความกว้างตัวบน | 28 mm |
| ความสูงรวม (ปิดอยู่) | 46 mm |
| ระยะแกนหมุนจากท้ายตัวบน | 6 mm |

## 👣 ลงมือทำ (4 นาที)
1. ถ่ายภาพ **ด้านข้าง** ของแม็กเย็บแบบตั้งฉาก วางไม้บรรทัดไว้ด้านล่างในภาพ แล้ว crop ให้เหลือแค่ตัวแม็ก
2. เปิด `PD_mm_template.fmz` แล้ว **Save As** เป็น `C2_Stapler.fmz`
3. ที่ **Reference Plane tool palette** เปลี่ยนเป็นระนาบ **ZX** (ระนาบตั้งที่มองจากด้านหน้า)
4. **Palettes > Reference Plane Parameters** เปิด **Underlay** แล้วกดไอคอน Open ข้างช่อง Underlay > **Load...** เลือกภาพ
5. ปรับขนาดและตำแหน่งภาพในหน้าต่าง Underlay จน **ไม้บรรทัดในภาพยาวตรงกับกริด** (เช่น 100 mm ในภาพ = 10 ช่องเส้นหนา)

{: .shot }
[SCREENSHOT: Reference Plane Parameters palette ที่เปิด Underlay และมีภาพด้านข้างของแม็กเย็บบนระนาบ ZX]

{: .verify }
ช่องปรับขนาดและตำแหน่งภาพในหน้าต่าง **Underlay** ของ v10 ยังไม่ได้ยืนยัน (คู่มือบอกแค่ Load... และ OK) ให้จับภาพหน้าจอจริงแล้วเติมชื่อช่องลงในบทนี้

{: .easy }
เหมือนการ import ภาพมาวางเป็น reference ใน SketchUp แต่ formZ ผูกภาพไว้กับ **reference plane** สลับระนาบก็ใช้ภาพคนละภาพได้ (หน้า / ข้าง / บน)

{: .shapr }
Shapr3D ใช้ **Image import** วางบนระนาบเหมือนกัน หลักการคือวาดเส้นทับภาพ ใน formZ เรียกว่า **Underlay**

<div class="challenge" markdown="1">
🏆 **ท้าทาย 5 นาที:** วัดของอีก 1 ชิ้นบนโต๊ะ (เช่น ยางลบ) แล้วจด 3 ค่าหลักใน 1 นาที
</div>
