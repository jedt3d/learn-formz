# 1. ปั้นตัวเครื่องใน 10 นาที
{% include meta.html %}

## 🎯 จบบทนี้แล้วเราจะ...
- ปั้นตัวเครื่องปิ้งขนมปังด้วยเครื่องมือที่รู้จักแล้ว (ทวน C1–C3)
- ทำ **ช่องขนมปัง 2 ช่อง** ด้วย **Insert + Cut**
- เตรียมไฟล์ `C4_Toaster.fmz` สำหรับงานภาพทั้ง course

## 💡 ไอเดียสั้น ๆ
ภาพที่สวยไม่ได้มาจากโมเดลที่ซับซ้อน แต่มาจาก **ฟอร์มที่เรียบร้อย + ขอบมนที่รับแสง** วัดเครื่องปิ้งที่บ้าน (**ถอดปลั๊กและรอให้เย็นก่อน**) ถ้าไม่มี ใช้ขนาดตัวอย่างนี้

| ส่วน | ค่า |
|---|---|
| ตัวเครื่อง | 280 × 170 × 190 mm (ยาว × ลึก × สูง) |
| ขอบแนวตั้ง | R25 · ขอบบน R10 |
| ช่องขนมปัง | 2 ช่อง ช่องละ 135 × 32 ลึก 150 · ห่างกัน 20 |

## 👣 ลงมือทำ (5 นาที)
1. เปิด template แล้ว **Save As** `C4_Toaster.fmz`
2. **Cube** (Diagonal) จาก (−140, −85, 0) ถึง (140, 85, 0) สูง **190** ตั้งชื่อ `Body`
3. **Controlled Round** set 1: ขอบแนวตั้ง 4 เส้น **R25** · set 2: ขอบบนรอบชิ้น (command-click) **R10**
4. **Rectangle** + **3D Extrusion** + **Insert: Cut** วาดบนหน้าบนเป็นช่อง 135 × 32 ลึก 150 ช่องแรกที่ y = −42..−10 และช่องที่สองที่ y = 10..42
5. ลบมุมปากช่อง R2 ด้วย Controlled Round (เพิ่ม set ใหม่) แล้วบันทึก

{: .shot }
[SCREENSHOT: Body หลังลบมุมและเจาะช่อง 2 ช่อง]

{: .warning }
ถ้าทำ Controlled Round หลัง Insert แล้ว error ให้ Undo แล้วสลับลำดับ: ลบมุม R25/R10 ก่อน แล้วค่อย Insert ช่อง (กฎ "ลบมุมก่อน" จาก C1)

{: .easy }
ทั้งหมดนี้คือเครื่องมือ 3 ตัวที่เรารู้จักแล้ว ใช้เวลาไม่ถึง 10 นาที
