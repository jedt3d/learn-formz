## ร่างบทเรียน
1. ปั้นเร็ว: Subdivision / Create + Soften หรือ Cube + Controlled Round, ช่องขนมปังด้วย Difference
2. Material Library + My Library (โลหะ chrome / brushed, พลาสติก, ยาง)
3. Map Texture / Edit Texture / Decal (โลโก้)
4. แสงสตูดิโอ: Area / Line lights, Environment light (HDRI)
5. Global Illumination / Ambient Occlusion / Catcher
6. คุณภาพเทียบกับเวลา (RenderZone Efficiency) · ไม่ใช้ Postprocess
7. Workshop: ภาพชุด 3 มุม (~60 นาที)
