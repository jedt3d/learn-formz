{: .note }
course นี้ **อยู่ระหว่างวางแผน** โครงด้านล่างคือร่างบทเรียนที่จะเขียนต่อ

**ชิ้นงาน:** ขวดน้ำ 500 ml (NURBS) หรือเคสหูฟัง (SubD)

## ร่างบทเรียน
1. Curve Create / Curve Edit / Curve Blend
2. Revolve, Axial Sweep, Pipe* (Derive 2)
3. Loft: Ruled / Tangent / Guided, Skin, NURBS by Lofting
4. NURBS Surface Blend / Merge + Surface Analysis (Zebra Stripes)
5. Subdivision / Create, Soften, Convert
6. Subdivision edit: Grow Face, Offset Face, Squeeze, Bridge
7. Smooth → solid (Convert Object Type, Display Resolution)

<small>* = formZ Pro เท่านั้น · อ้างอิง R1: NURBS Curves/Surfaces, Lofting, Subdivision Surfaces, Surface Analysis</small>
