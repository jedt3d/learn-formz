# 5. Revolve: ตัวกาในคลิกเดียว
{% include meta.html %}

## 🎯 จบบทนี้แล้วเราจะ...
- หมุนโปรไฟล์รอบแกนด้วย **Revolve** ให้ได้ผิวทรงกลม
- รู้จักตัวเลือก **Angle / Direction / Revolve Type (Continuous / Stepped) / Cap**
- ใช้ **Thicken** ให้ตัวกามีผนังหนา 2 mm

## 💡 ไอเดียสั้น ๆ
ของที่ "กลม" ในบ้าน เช่น แก้ว ขวด กาน้ำ ชาม ทำได้จาก **โปรไฟล์ครึ่งเดียว + Revolve** เหมือนการปั้นบนแป้นหมุน (R1: Revolve)

| ตัวเลือก | ใช้ทำอะไร |
|---|---|
| **Angle** | 360° = รอบเต็ม · น้อยกว่านั้นได้ผลแบบผ่าครึ่ง (ใช้โชว์ด้านในได้) |
| **Revolve Type** | **Continuous** = smooth · **Stepped** = เป็นปล้อง (# Of Steps) |
| **Cap** | ปิดปลายเมื่อหมุนไม่ครบรอบ (ใช้กับรูปปิด) |

แกนหมุน (axis) ใช้ได้ทั้ง **วัตถุอื่น** (เช่น เส้นตรง) หรือ **แกนของระบบพิกัด**

## 👣 ลงมือทำ (3 นาที)
1. เลือก **Revolve** แล้วตั้ง Angle **360** และ Type **Continuous**
2. คลิกเส้นโปรไฟล์ แล้วเลือกแกน **Z** เป็นแกนหมุน (หรือวาดเส้นตรงตามแกน Z ไว้ก่อนแล้วคลิกเส้นนั้น)
3. ทำซ้ำกับเส้นก้น จะได้แผ่นก้นกลม
4. ใช้ **Stitch** ต่อผิวข้างกับก้นเข้าด้วยกัน (หรือข้ามขั้นนี้ ถ้าบทที่แล้วต่อเส้นไว้แล้ว)
5. **Thicken** **2 mm** (ความหนาไปด้านใน) ตั้งชื่อ `Body` แล้วบันทึก
6. ลองตั้ง Angle เป็น **180** ดูแบบผ่าครึ่ง แล้วตั้งกลับ 360

## ✅ เช็คตัวเอง
<details><summary>1. Stepped ใช้ทำอะไร?</summary>ได้รูปเป็นปล้อง ๆ (facetted ตามจำนวนขั้น) เช่น ฝาเกลียวแบบเหลี่ยมหรือโคมไฟทรงเหลี่ยม</details>
<details><summary>2. ทำไมต้อง Thicken?</summary>เพราะ Revolve โปรไฟล์เปิดได้ผิวบางเป็นศูนย์ ต้องเพิ่มความหนาให้เป็น solid</details>
<details><summary>3. จะเปิดดูด้านในแบบผ่าครึ่งทำอย่างไร?</summary>ตั้ง Angle = 180</details>

📚 อ้างอิง: R1 Revolve, Thicken, Stitch
