# SP2 · Render Diagnosis #1: แก้ 3 จุด ภาพสวยขึ้นทันที
{% include meta.html %}

## 🎯 จบบทนี้แล้วเราจะ...
- อ่านภาพ render เป็น 3 ชั้น: **กล้อง → แสง → วัสดุ**
- แก้แต่ละชั้นด้วยเครื่องมือเดียวแล้วเห็นผลทันที

## 💡 ไอเดียสั้น ๆ
หมอดูอาการก่อนจ่ายยา ภาพ render ก็เหมือนกัน ถามทีละข้อ:

| ชั้น | อาการ | ยา |
|---|---|---|
| 📷 **กล้อง** | ของดูบิด / เหมือนมองจากเพดาน / ตกขอบ | มุมสูงระดับตาสินค้า, เลนส์ยาวขึ้น (50–85 mm 🔍), จัดกลางเฟรม |
| 💡 **แสง** | แบน ไม่มีเงา หรือเงาดำสนิท | Area light ใหญ่ด้านข้าง 45° + แสงเติมอ่อน ๆ + Environment |
| 🎨 **วัสดุ** | เหมือนพลาสติกของเล่น / ไม่มีขอบสะท้อน | เพิ่ม Reflection เล็กน้อย, ใส่ Bump บาง ๆ, ขอบมนเพื่อให้มีไฮไลต์ |

## 👣 ลงมือทำ (10 นาที)
1. เปิดไฟล์ตัวอย่าง `SP2_toaster_bad.fmz` 🔍 (หรือใช้เครื่องปิ้งขนมปังจาก C4 แล้วตั้งค่าให้ "แย่" เอง: มุมบนลงล่าง, แสงตรงหน้าดวงเดียว, วัสดุไม่มี reflection)
2. **ข้อ 1 · กล้อง**: ปรับ view ให้ต่ำลงระดับสินค้า เลนส์ยาวขึ้น → render เล็ก → เก็บภาพ
3. **ข้อ 2 · แสง**: ลบแสงหน้า ใส่ **Area light** ด้านข้าง + แสงเติม → render → เก็บภาพ
4. **ข้อ 3 · วัสดุ**: เพิ่ม Reflection / Bump ให้ตัวเครื่องและปุ่ม → render → เก็บภาพ
5. วางภาพ 4 ภาพเรียงกัน: ก่อน → +กล้อง → +แสง → +วัสดุ
